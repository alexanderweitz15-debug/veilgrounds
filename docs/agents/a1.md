## Deviations from the prompt (with reason) - DECISIONS proposals

- **Delay queue kept for non-lane nodes** (§3 says "replaced by plans"; lead decision e accepts it). Rule: no lane
  command uses `delay` or tag `'lh'` any more (grep: `laneLeaf` has no `delay`, `planLastHit` is no longer called;
  the reflex layer returns no delayed actions). `busyUntil` still drops delayed move/attack of other nodes.
- **Reflex snapshot is not buildSnapshot** (0.76 ms per call): per-team entity view with the same fog rule, built
  by the runner, passed through `onPerceive` (plan-api Changes 1).
- **No reaction share in the timing error** (§4.2): `biasTicks ~ N(0, lastHitJitterMs)` per plan; the reaction part
  is A3's attention model.
- **csLossByCause has an 11th cause `ally_took`** (an allied champion got the CS); `enemy_took` = zoned (enemy
  champion within 900 while out of reach), because the enemy laner cannot kill the bot's CS minions.
- **attackUtilization denominator**: ticks 2:00-14:00 with an enemy minion or champion within range + radii + 200;
  numerator: own attack cycle running (wind-up or backswing). **idleShare**: same denominator; idle = no command for
  > 45 ticks AND no attack cycle AND not walking (a bot auto-repeating one attack command is not idle).
- **Lane-alone scenario drops recall/ward commands and sets the vision axis to -5** (a practice-tool session):
  otherwise recall trips decide the number, not last hitting.
- **Filler rule 2 strict**: a filler hit may not open the minion's kill window before the bot's next auto can land
  (spec wording), plus 3 ticks of slack for every protected window.

- **Test 11 is a regression bound, the target is reported** (supervisor finding): the reflex cost depends on the
  CPU load of the shared machine (0.04 ms alone, 0.13-0.15 ms with six agents running, same code). The test asserts
  < 0.5 ms per bot and tick; the §3 target 0.05 ms is checked in `bot-sim --report` ("Reflex cost ms per bot and
  tick") on an idle machine. View cost (per-team snapshot) is reported separately (`viewMs`).
- **movesWhileCasting** (B2): casts of such abilities no longer set `busyUntil` (think and reflex), channels still do.
