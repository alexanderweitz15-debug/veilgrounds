### Real-game regression (lead report 2.68 on vs 3.08 off, Gold seed 1)

Single-seed difference, not systematic: over seeds 1-4 the first reflex build already had 3.08 vs 2.98. Causes
found with `csLossByCause` on/off and two scratch traces: (1) reflex bots stood in reach of enemy minions with no
own minion near them and took minion aggro -> lower HP -> more recalls (5.0 -> 7.3 per laner in 12 min) and recalls
broken by caster minions (18 vs 6 broken recalls on seed 1; recall safety radius 650 < caster reach ~663, see
"Questions"); (2) a third of the in-lane losses were empty kill windows (a stacked hit jumps over the own damage).
Fixes: stand outside untanked minions' reach, fillers only on tanked minions, pre-hit filler for empty windows,
joint window protection. Result above (3.27 vs 2.90). Recalls are still higher with reflex (5.7 vs 4.9 per laner,
more CS -> more gold -> more gold recalls): Phase 3 shove-and-recall (A2) is where that belongs.

## Phase 2 (19-22 Oct)

- Harass filler (`harassTarget`): budget = harassPerMin + 0.6 x aggression per minute, counted on thrown autos;
  enemy champion within reach + 400 (step-up; spec 150, deviation below), not in the enemy tower's range, not inside
  the enemy wave (> 1 enemy minion within 350 of the attack spot, unless ranged vs melee; Iron-Bronze sometimes
  ignore it via the named error ignore_minion_aggro), Diamond+ prefer the enemy's CS window; hold = no step-up. A
  walk-in keeps going until the wind-up unless a last hit is due or the protection check fails.
- Wave states (`chooseWaveState`, reflex path only; legacy keeps macro.ts `chooseWave`): push / neutral / slowPush /
  freeze / hold, logged with reason (node `wave`), 10 s hysteresis, hold at gank risk >= 0.4 (never freeze),
  slowPush 60-90 s before an objective, push before a recall / objective < 60 s / dead enemy laner / team desire /
  minion advantage, freeze when the enemy laner is behind and the own jungler is not near (slow tempo raises it),
  deliberate-or-push rolled per minute with `waveStateDeliberatePct`. Fillers by state: push all; neutral/hold
  minions only while the own wave is not bigger; slowPush enemy melee only; freeze only minions that hit own minions
  or the tower while the enemy surplus is > 2; structures only in push.

## Deviations from the prompt (with reason) - DECISIONS proposals

- **Harass step-up 400 instead of 150** (§4.3): with 150 the enemy laner was in reach only on its own walk-ins.
- **Test 5 counts losses during reflex harass only** (a trade started by the combat leaf is the decision's farm
  cost); **test 6 asserts >= 1 auto per 2.5 s with minions in reach** (spec 2 s): at the own tower the tower shots
  keep opening last-hit windows that hold the attack timer.

- **Delay queue kept for non-lane nodes** (§3 says "replaced by plans"; lead decision e accepts it). Rule: no lane
  command uses `delay` or tag `'lh'` any more (grep: `laneLeaf` has no `delay`, `planLastHit` is no longer called;
  the reflex layer returns no delayed actions). `busyUntil` still drops delayed move/attack of other nodes.
- **Reflex snapshot is not buildSnapshot** (0.76 ms per call): per-team entity view with the same fog rule, built
  by the runner, passed through `onPerceive` (plan-api Changes 1).
- **No reaction share in the timing error** (§4.2): `biasTicks ~ N(0, lastHitJitterMs)` per plan; the reaction part
  is A3's attention model.
- **csLossByCause has an 11th cause `ally_took`** (an allied champion got the CS); `enemy_took` = zoned (enemy
  champion within 900 while out of reach), because the enemy laner cannot kill the bot's CS minions.
- **attackUtilization denominator**: ticks 2:00-14:00 with an enemy minion or champion within range + radii + 200;
  numerator: own attack cycle running (wind-up or backswing). **idleShare**: same denominator; idle = no command for
  > 45 ticks AND no attack cycle AND not walking (a bot auto-repeating one attack command is not idle).
- **Lane-alone scenario drops recall/ward commands and sets the vision axis to -5** (a practice-tool session):
  otherwise recall trips decide the number, not last hitting.
- **Filler rule 2 strict**: a filler hit may not open the minion's kill window before the bot's next auto can land
  (spec wording), plus 3 ticks of slack for every protected window.

- **Test 11 is a regression bound, the target is reported** (supervisor finding): the reflex cost depends on the
  CPU load of the shared machine (0.04 ms alone, 0.13-0.15 ms with six agents running, same code). The test asserts
  < 0.5 ms per bot and tick; the §3 target 0.05 ms is checked in `bot-sim --report` ("Reflex cost ms per bot and
  tick") on an idle machine. View cost (per-team snapshot) is reported separately (`viewMs`).
- **movesWhileCasting** (B2): casts of such abilities no longer set `busyUntil` (think and reflex), channels still do.
