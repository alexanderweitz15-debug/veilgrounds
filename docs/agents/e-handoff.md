# Agent E handoff - Sev Aschenblick (Fassung 3)

State: Sev is the Itachi-inspired genjutsu mage of Fassung 3 with a per-match R choice (Amaterasu / Susanoo /
Tsukuyomi), stronger Q/W AoE after the user's AoE feedback, new sprite with crows, per-ability ground effects.
Branch `champ/e-sev`, merges into main without conflicts. Details, commits, numbers, open items: `docs/agents/e.md`.

Where things live:
- Data: `src/data/champions/sev.json` (abilities, `ultChoices`, `botUltChoice`), build, rune presets, motif row
  (7 motifs incl. the ults) in `src/render/abilityMotifs.json`.
- Sim: `src/sim/champions/sev.ts`; R choice engine in `src/sim/systems/abilities.ts` (`chooseUlt`, `ultChoiceOf`,
  `botUltPick`, `abilityOf`), command `ultChoice` (input.ts/types.ts), `SnapEntity.ult`, `AbilityHud.ultChoice`.
- Client: `abilityForSlot` / `ultDisplaySlot` in `src/data/champions/index.ts` (virtual slots 4..6 = the three ults),
  cards `src/ui/ultChoice.ts`(+css), ground FX `src/render/sevFx.ts` (hooked in groundObjects.ts), sprite props
  `src/render/champions/sev.ts` + kit entry in kits.ts.
- Tests: `tests/sev.test.ts`; combos/castMovement pick the first ult for champions with a choice.
- Tools: `npx tsx tools/scratch/sevCasts.ts [games] [min] [rank] [seed]` (Sev blue mid, casts, ult, CC, vs red mid).

Screenshot driver: headless Edge over CDP (`node shot.mjs <url> <steps.json>`), steps generated by `gen3.py`
(sandbox -> Sev -> setLevel 18 -> cards -> key 1/2/3 -> Q/E/W/R); needs `?bench` and a vite dev/preview server.
