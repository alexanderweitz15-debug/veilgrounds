## 4.8 Profile with history (done)

- Pure aggregation `src/game/profile.ts`: `championStats` (classic games only, CS/gold per minute weighted by game length),
  `overview`, `rankTrend` (one point per calibrated game = mean of the category indices from `calibrateMatch`),

## 2.8 All chat (done)

- Shift+Enter or `/all text` sends a line to both teams: `all?: boolean` on the `chat` Command and SimEvent (src/sim/types.ts), copied in `chat()` (src/sim/systems/input.ts), delivered to both teams in `teamEvents` (src/sim/snapshot.ts). Tag `[Alle]`/`[All]` in the chat box (src/ui/chat.ts).
- Enemy bots may answer: `allChatReply` in src/ai/bot/social.ts (additive, uses the 45 s chat throttle); chance per band and delay in src/data/bots/allchat.json; 9 lines `cat: allReply` in src/data/bots/chat.json. Team chat gets no answer from the enemy.
- Test: tests/allChat.test.ts (3 cases).

## 2.10 Surrender vote (done)

- Sim: src/sim/surrender.ts (commands `ff` = start, `ffVote`; event `ff` with full tally, team-private; system `surrenderSystem`). Classic mode only, humans start it, from 15:00; vote 30 s; before 20:00 all voters, then ceil(0.8 x voters); 3 min pause after a failed vote; a passed vote sets `winner` + `gameOver`. State `sim.state.ff` is created on the first vote, so games without a vote keep their state hash (replay test green).
- Bots: `surrenderVote` in src/ai/bot/social.ts. Score = weighted gold (item value) / kill / tower deficit + tilt bonus, 0..1; yes when score >= threshold of the rank band (low 0.3, mid 0.5, high 0.7); reaction delay 2-12 s; says `surrender_yes` / `surrender_no`. All numbers: src/data/surrender.json.
- UI: src/ui/surrenderPanel.ts (+ surrender.css): voter chips, tally, countdown bar, Yes/No buttons and F5/F6. `/ff` in the chat box starts the vote (replaces the old "not possible" line). Client fold: src/game/surrender.ts.
- Test: tests/surrender.test.ts (11 cases incl. bots answering a started vote).
