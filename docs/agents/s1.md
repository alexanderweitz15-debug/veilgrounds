## 4.8 Profile with history (done)

- Main menu nav entry "Profil" -> `profileScreen()` in src/main.ts -> `src/ui/profileScreen.ts` (+ profile.css).
- Pure aggregation `src/game/profile.ts`: `championStats` (classic games only, CS/gold per minute weighted by game length),
  `overview`, `rankTrend` (one point per calibrated game = mean of the category indices from `calibrateMatch`),
  `currentEstimate` (mean of the last 5 calibrated games, delta against the 5 before), `recent`. Streaks come from
  `streaks()` in src/stats/history.ts.
- Additive in D's area: `MatchRecord.assists?` (src/stats/history.ts) and `MatchSummary.assists?` (src/game/matchStats.ts,
  from the own scoreboard row) so KDA is real; older records count assists as 0.
- Only games >= 10 min are calibrated (existing rule in `recordFromSummary`), shorter games are listed without a rank.
- Test: tests/profile.test.ts (10 cases). i18n: `profile.*`, `menu.profile` (de + en).
- Screenshots (1280x720, built game, synthetic 15-record history seeded into IndexedDB): docs/ist/s1-profile-before.jpg
  (main menu without the entry), s1-profile-1.jpg (overview, trend, champions), s1-profile-2.jpg (match list).
